# avload: 認証ベクターAPI の取得先の負荷の道具

認証ベクターAPI の取得先（aka-vecgen など）に一定の速さで要求を送り、応答の時間を測る道具と、その結果。認証ベクターAPI の契約（`docs/av-api-contract.md`）§11.1 の目安（毎秒 100 要求で p99 200 ミリ秒）に照らす。段階 6 の規模の試験（概要 §16.1）でも使う。

## 道具

- 加入者の登録（`-setup`）は、取得先の管理API（aka-vecgen の `POST /admin/v2/subscribers`）で行う。鍵は試験用の決まった値（TS 35.208 の試験セット 1）。既にあれば 409 を許す。
- 測る間は、`-rate` 回/秒で要求を送り続ける（前の要求の終わりを待たない）。偶数番は EAP-AKA、奇数番は EAP-AKA'（`anId` は `WLAN`）。IMSI は `-prefix` と通し番号で、`-n` 件を順に回す。
- 接続は使い回す（keep-alive。契約 §5）。
- 結果は JSON の 1 行（要求の数、200 の数、ステータスごとの数、通信の失敗、実際の速さ、p50・p95・p99・最大のミリ秒）。全部が 200 でなければ終了コード 1。

```bash
go build -o avload .
./avload -url https://127.0.0.1:18443/nudm-ueau/v1 -ca av-server.pem -cert av.pem \
  -admin-url https://127.0.0.1:19443 -admin-ca admin-server.pem -admin-cert admin.pem \
  -setup -n 10000 -rate 100 -duration 60s -label example
```

`-cert` と `-admin-cert` は、証明書と秘密鍵を 1 つにした PEM。AV クライアントは `aka-vecgen client add`、管理クライアントは `VECGEN_ADMIN_CLIENTS` に登録しておく。

## 結果

### V22: aka-vecgen 2-2 の鍵の暗号化（2026-10-28）

aka-vecgen の段階 2-2（Ki・OPc を KEK で暗号化し、要求ごとに復号する）で、応答の時間が変わらないかを確かめた（aka-vecgen の設計概要 §16 の 2-2 の「終わりの確かめ」）。結果の生のデータは `results/2026-10-28-vecgen-2-2.jsonl`。

- 検証機（simwifi。Debian 13、Docker 29.8.2、N100・16 GB）で、aka-vecgen の compose（Valkey は `appendfsync always`）をそのまま立てた。イメージは手元でビルドし、`docker save` で渡した。
- 比べたもの: `base` は 2-1（`9dd9815`、鍵は平文）、`kek` は 2-2（鍵を暗号化）。
- 条件: 加入者 1 万件、毎秒 100 要求を 60 秒（6,000 要求）、同じ検証機の上で道具を動かした。`base` → `kek` → `base` → `kek` の順に 2 回ずつ。毎回 Valkey を作り直した。

| 回 | p50 | p95 | p99 | 最大 | 200 の数 |
|---|---|---|---|---|---|
| base 1 回目 | 3.28 ms | 4.86 ms | 76.5 ms | 236 ms | 6,000 / 6,000 |
| kek 1 回目 | 3.35 ms | 4.50 ms | 51.0 ms | 248 ms | 6,000 / 6,000 |
| base 2 回目 | 3.29 ms | 4.58 ms | 6.45 ms | 9.1 ms | 6,000 / 6,000 |
| kek 2 回目 | 3.34 ms | 5.65 ms | 6.39 ms | 9.0 ms | 6,000 / 6,000 |

- 暗号化による差は、測った範囲では見えない（p50 の差は 0.06 ミリ秒前後で、回ごとの揺れの中）。
- どの回も、契約 §11.1 の目安（p99 200 ミリ秒）の内に入った。
- 1 回目は、平文・暗号化のどちらも p99 と最大が大きかった（最大で 200 ミリ秒を少し超えた要求がある）。2 回目にはなくなったので、暗号化ではなく、計測を始めたばかりの検証機の状態（CPU のクロック、ページキャッシュなど）によると見ている。段階 6 の規模の試験では、慣らしの時間をおいてから測る。
- 加入者 1 万件の登録（8 並列の管理API）は約 14 秒（毎秒約 700 件）。
- 測り終えたときのメモリーは、aka-vecgen が 21〜23 MiB、Valkey が 15〜16 MiB だった。

## 片付け
