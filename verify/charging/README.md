# verify/charging: 課金レコードのファイルの確かめ

課金レコードの月次のまとめ（`charging_<YYYYMM>_<通し番号>_v<版>.zip.pgp`）を、外部の一般的な道具（`gpg`・`unzip`・`sha256sum`）で読んで確かめる道具と、その結果（`docs/charging-records.md` §12）。外部のシステムが取り込むときの手順の見本にもなる。

## 道具

`verify-file.py` は、ファイルを `gpg` で復号して `unzip` で展開し、次を確かめる。全部が合えば終了コード 0。

- ファイルの名前と manifest の `period`・`sequence`・`version` が合う。
- PGP の完全性の検査を通る（改ざんしたファイルは失敗する）。PGP の圧縮のパケットがない。
- ZIP の中が 5 つのファイルで、manifest の件数と SHA-256 が合う。
- CSV が RFC 4180 の形（CRLF、BOM なし）で、すべての行が同じ列を持ち、列の名前が §7 のとおり。
- `record_id` の形と重複、`period`、時刻の形（`+09:00`）、状態と真偽値の値。

```bash
GNUPGHOME=<秘密鍵のある鍵束> verify/charging/verify-file.py charging_202611_000001_v1.zip.pgp
```

`-o <ディレクトリ>` を付けると展開した CSV を残す（平文なので、確かめた後に消す）。付けなければ終わりに消す。検証機には `gpg`・`unzip` がないので、手元で動かす。

## 結果

### 2026-10-30: aka-ossbss 段階 3-4 の手元の確かめ

aka-provisioner `ff21ac4`・aka-vecgen `2d48379`・aka-radius `ac2f05a`（aka-provisioner の `scripts/contract.sh` で起動した本物）につなぎ、手元の PostgreSQL 18.6（既定の設定）で動かした。月の境目は、試しの DB の `charging_events.time` と `usage_daily.date` を SQL で前の月に動かして作った（製品のコードに試し用の口はない）。利用の集計は aka-radius の Valkey に置き、aka-provisioner を通して取り込んだ。

| 確かめたこと | 結果 |
|---|---|
| 登録・状態の変更・付け替え・物理削除の事実から月次の行を作る | 手の計算と一致（付け替えは行が分かれ、付け替えの日は両方に数える。11 日の回線の Active の日数など） |
| 利用の行が刻印のテナントのまま | 登録と違うテナントと刻印なしは `registered_days` が 0 の行 |
| 取り込めなかった日 | その日に登録されていた行だけ `usage_complete=false` |
| 鍵なしの締め | 計算だけ残して保留。画面と `CHARGING_KEY_WARN` で警告。鍵を登録するとすぐ作る |
| 訂正 | 前の月の利用を増やして次の月を締めると、`lines_adj.csv` に全体が 1 行。元の行は変わらない |
| 鍵の入れ替えと作り直し | 古い版は古い鍵のまま、新しい版は今の鍵で復号できる。`record_id` は同じで版が上がる |
| 鍵の確かめ | RSA 2048、暗号化の副鍵のない鍵、秘密鍵を断る |
| `verify-file.py` | 3 つのファイルが通り、1 バイト変えたファイルは `gpg` が拒否した |
| 締めの途中の SIGTERM | 0.05 秒で止まり、その月の行は何も残らない。記録は中断で、起動の後に締め直す |
| aka-radius が止まっている間の締め | 取り込みは失敗（`USAGE_IMPORT_ERR`）したが、締めとファイルは済む |

規模の目安（回線 20 万件・テナント 1,000・事実 41 万件・全回線が毎日使う利用 1 か月 600 万行。WSL の手元で、目標は締めから 30 分以内）:

| 項目 | 結果 |
|---|---|
| 計算（事実 41 万件の月） | 12 秒 |
| 計算（事実のない月。前の月の 600 万行との訂正の比較を含む） | 17 秒 |
| ファイルの生成 | 6 秒（7.0 MB）、2 秒（1.9 MB） |
| 2 か月分の全体（取り込み・計算・ファイル） | 36.5 秒 |
| aka-ossbss のメモリーの最大 | 約 100 MiB |
| 利用の集計の容量 | 1 か月 600 万行で約 880 MB（索引を含む）。13 か月で 11〜12 GB の見込み |
| 回線の月次の容量 | 1 か月 20 万行で約 48 MB |

検証機での確かめは段階 3 の終わりの通し（Q8）、20 万件の規模の試験は段階 6 で行う。
